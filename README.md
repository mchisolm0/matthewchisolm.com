# matthewchisolm.com

Built on [AstroPaper](https://github.com/satnaing/astro-paper). Deployed to Cloudflare Workers on push to `main`.

- Write: add a `.md` or `.mdx` file to `src/content/posts/`. Set `draft: true` to keep it unpublished.
- Preview: `pnpm dev`
- Update the template: `git fetch upstream && git merge upstream/main`
